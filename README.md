
🚀 Code Collaborative Editor

A real-time collaborative code editor that allows multiple users to write, edit, and share code simultaneously. Built for seamless teamwork, live coding interviews, and learning environments.

✨ Features
👥 Real-time collaboration
🧠 Live code synchronization
💬 In-app chat support
🌐 Multi-user rooms
⚡ Fast and responsive UI
📝 Syntax highlighting
🔒 Secure room-based access
🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript / React
Backend: Node.js, Express
Realtime: Socket.IO
Database: (Add if you used any)
Deployment: (Vercel / Render / etc.)

⚙️ Installation
git clone https://github.com/bhuvaneswari-visakha/code-collaborative-editor.git
cd code-collaborative-editor
npm install
npm start

🚀 Usage
Open the app
Create or join a room
Share the room ID with others
Start coding together in real-time 🎉
